# EquicordTranslator

Пользовательский плагин Equicord для перевода описаний плагинов, названий и пояснений в их настройках, а также текста на страницах настроек Equicord. Доступно более 60 языков; по умолчанию выбран русский.

## Установка

1. Скопируйте папку `equicordTranslator` в `src/userplugins/` исходников Equicord.
2. Из папки репозитория выполните `pnpm build`, затем подключите сборку к своему клиенту способом, указанным в документации Equicord.
3. Полностью перезапустите Discord и включите **EquicordTranslator** в настройках Equicord → Plugins.
4. Откройте настройки плагина, выберите язык в поле **Translation Language**. Плагин повторно переведёт описания и открытую страницу без перезапуска; настройки отдельного плагина переведутся при открытии его окна.
5. Чтобы обновить список описаний, закройте и снова откройте страницу Plugins.

При переименовании плагина из `RussianPluginDescriptions` его прежнее включённое состояние переносится автоматически. Русский перевод из старого локального кеша тоже сохраняется.

## Перевод и приватность

Перевод выполняет Google Translate. В Google отправляются описания плагинов, видимый текст их настроек и текст поддерживаемых страниц настроек Equicord; сообщения Discord, токен и данные профиля плагин не читает. Результаты кешируются локально отдельно для каждого языка. Переключение языка использует отдельный кеш и автоматически обновляет текущий перевод.

Доступность используемого Google Translate endpoint не гарантируется. Машинный перевод может быть неточным.

## Поддерживаемые страницы

Настройки Equicord, Themes, Updater, Changelog, Cloud, Backup & Restore, Patch Helper и открытые окна настроек плагинов. На других страницах плагин автоматически ничего не меняет.
