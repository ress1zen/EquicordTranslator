# EquicordTranslator

Пользовательский плагин Equicord для перевода описаний всех плагинов и текста на страницах настроек Equicord на выбранный язык. Доступно более 60 языков; по умолчанию выбран русский.

## Установка

1. Скопируйте папку `equicordTranslator` в `src/userplugins/` исходников Equicord.
2. Из папки репозитория выполните `pnpm build`, затем подключите сборку к своему клиенту способом, указанным в документации Equicord.
3. Полностью перезапустите Discord и включите **EquicordTranslator** в настройках Equicord → Plugins.
4. Откройте настройки плагина, выберите язык в поле **Язык для описаний плагинов и страниц настроек Equicord**. Плагин повторно переведёт описания и открытую страницу без перезапуска.
5. Чтобы обновить список описаний, закройте и снова откройте страницу Plugins.

При переименовании плагина из `RussianPluginDescriptions` его прежнее включённое состояние переносится автоматически. Русский перевод из старого локального кеша тоже сохраняется.

## Перевод и приватность

Перевод выполняет Google Translate. В Google отправляются описания плагинов и видимый текст поддерживаемых страниц настроек Equicord; сообщения Discord, токен и данные профиля плагин не читает. Результаты кешируются локально отдельно для каждого языка. Переключение языка использует отдельный кеш и автоматически обновляет текущий перевод.

Доступность используемого Google Translate endpoint не гарантируется. Машинный перевод может быть неточным.

## Поддерживаемые страницы

Настройки Equicord, Themes, Updater, Changelog, Cloud, Backup & Restore и Patch Helper. На других страницах плагин автоматически ничего не меняет.
